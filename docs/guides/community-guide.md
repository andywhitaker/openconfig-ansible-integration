# Community Guide

`nokia.openconfig` is an open-source project led by Nokia and maintained together with community contributors. There is no commercial support and no SLA; help comes from the documentation, issues and discussions.

## Ways to contribute

- **Bug reports** — [GitHub Issues](https://github.com/nokia-steward/openconfig-ansible-integration/issues) with reproduction, versions, and logs.
- **Features** — Discuss in Issues or Discussions before large changes.
- **Pull requests** — See [Developer Guide](developer-guide.md) and CONTRIBUTING on GitHub.
- **Documentation** — Fix typos or clarify guides under `docs/`; run `make docs` if you change module docstrings.

## Code of conduct

Follow the [Ansible Community Guidelines](https://docs.ansible.com/ansible/devel/community/code_of_conduct.html) and treat other contributors respectfully.

## Releases

Tagged releases are published to [Ansible Galaxy](https://galaxy.ansible.com/ui/repo/published/nokia/openconfig/) and attached to the [GitHub release](https://github.com/nokia-steward/openconfig-ansible-integration/releases). The documentation describes the 2.0.0 release line. Pre-release versions, such as `2.0.0`, are only installed when requested explicitly, see [Installation](../getting-started/installation.md).

Thank you for improving OpenConfig automation for the community.
