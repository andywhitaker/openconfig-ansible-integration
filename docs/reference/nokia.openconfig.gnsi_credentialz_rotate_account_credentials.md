# Ansible Module: nokia.openconfig.gnsi_credentialz_rotate_account_credentials

**Rotate account credentials over gNSI**

!!! note "Notes"

    Requires [`nokia.openconfig.grpc`](nokia.openconfig.grpc.md).

    Supported on Nokia SR Linux. gNSI must be enabled on the gRPC server.

    Reports `changed=true`. In check mode the RPC is not sent and the task is skipped.

    Bidirectional streaming RPC with a request sequence defined by the playbook. The [`stream`](#param-stream) messages are sent in the given order without waiting for responses, and every server message is collected until the device closes the stream. The task cannot react to intermediate responses, so a rotation that needs data from the device within the same stream, such as signing a CSR generated by the device, is not possible. The device rolls back the rotation if the stream closes without a finalize message, so end [`stream`](#param-stream) with `finalize`.

    Not exercised by the collection integration tests on Nokia devices; covered by unit tests against the gNOI/gNSI mock server.

## Synopsis

* Invokes gNSI `Credentialz.RotateAccountCredentials`, sending the [`stream`](#param-stream) messages in order and returning all server messages.

## Parameters

| Parameter | Type | Comments |
| --- | --- | --- |
| stream {#param-stream} | list | Client messages in send order. Each item holds the protobuf JSON fields of one `RotateAccountCredentialsRequest`.<br/>**Required:** always |

## Examples

```yaml
- name: Set authorized keys for a user and finalize (SR Linux)
  nokia.openconfig.gnsi_credentialz_rotate_account_credentials:
    stream:
      - credential:
          credentials:
            - account: automation
              version: v1
              createdOn: 1700000000
              authorizedKeys:
                - authorizedKey: "{{ lookup('file', 'id_ed25519.pub').split()[1] }}"
                  keyType: KEY_TYPE_ED25519
      - finalize: {}
```
## Return Values

| Parameter | Type | Comments |
| --- | --- | --- |
| output {#return-output} | str | Response messages as a JSON list in stream order (protobuf JSON names).<br/>**Returned:** success |
